🗂 Your 3 Files — That's All You Need

content.js ✏️ The only file you ever edit. All text, lessons, FAQs, and settings live here. Think of it as your notebook.
index.html The website structure. Never touch this unless changing layout design.
app.js The engine that reads content.js and builds the page. Never touch this.
admin/login.html This password-protected login page. Hidden from Google.
admin/guide.html This guide. Only accessible after logging in. Hidden from Google.
✅ Golden rule: Every day, the only file you open is content.js. That's it. Everything else runs automatically.

🚀 GitHub Pages Setup (Free Hosting — Do This Once)

Cost: £0 / $0 forever. GitHub Pages is completely free. Your site lives at your-username.github.io/curiositas-ai — or point your curiositas.ai domain to it (~$10/year for the domain only).
1
Create a free GitHub accountGo to github.com → Sign up. Free.
2
Create a new repositoryClick the green "New" button. Name it curiositas-ai. Set to Public. Click "Create repository".
3
Upload all your site filesClick "uploading an existing file". Drag every file from your downloaded folder. Click "Commit changes".
4
Turn on GitHub PagesSettings → Pages → Source → select "main" branch → Save. Live in ~30 seconds.

Connect your own domain (curiositas.ai)

1
Buy the domainTry Namecheap or Porkbun — both are cheap (~$10/year).
2
Point DNS to GitHubIn your domain registrar, add these A records:
185.199.108.153, 185.199.109.153, 185.199.110.153, 185.199.111.153
3
Set custom domain in GitHubSettings → Pages → Custom domain → type curiositas.ai → Save. Tick "Enforce HTTPS".

📚 Add a New Lesson

Open content.js. Find the lessons: section. Before the closing ], paste:

{
  title:    "Your New Lesson Title",
  topic:    "Prompt Engineering",  // or "How AI Works"
  duration: "30 min",
  note:     "No background needed",
  level:    "starter",  // starter | explorer | builder
  link:     "lessons/lesson-11.html",  // optional: link to full lesson page
},
Important: Every block needs a comma , at the end — except the very last lesson in the list.

🆘 Troubleshooting

Site looks broken after editing content.js

Almost always: a missing or extra comma. Check every lesson/FAQ block ends with }, — except the last one which ends with just }. Undo your last change (Ctrl+Z) and try again carefully.

Changes not showing on live site

GitHub Pages takes up to 2 minutes. Hard refresh: Ctrl+Shift+R (Windows) or Cmd+Shift+R (Mac).

Adding a full lesson page

Create lessons/lesson-11.html using lessons/lesson-01.html as a template. Then in content.js add link: "lessons/lesson-11.html" to that lesson block — it becomes clickable automatically.

Someone found the admin page

Change the password in admin/login.html (find the line const OWNER_PASSWORD =). The page is already blocked from Google — no one can find it by searching.

🔑 Change Your Admin Password

Open admin/login.html in a text editor. Find this line near the top:

const OWNER_PASSWORD = "Curiositas2025!";

Replace Curiositas2025! with your new password. Save and upload. Done.

Good password tips: Mix uppercase, lowercase, numbers, and a symbol. At least 12 characters. Example: AIlearning#2025
Note: This is a client-side password — it protects casual visitors, not determined hackers. The admin pages are not linked from anywhere public and are blocked from Google, so the chance of anyone finding them is extremely low. For higher security in future, consider moving to a platform with server-side auth (Netlify, Vercel).
